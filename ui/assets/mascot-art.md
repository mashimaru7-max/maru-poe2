# Active mascot stickers

Asset: `docs/assets/mascot-stickers.webp` (768×768, transparent four-pose sprite sheet). Generated for this project on 2026-11-05 using the prior characters only as identity references. The earlier workshop landscape is not rendered by the active theme.

Art brief: four isolated full-body cute fantasy stickers in an equal 2×2 grid. Top-left: apricot crested-gecko adventurer waving with a parchment. Top-right: charcoal cat artisan examining a gold orb with a magnifier. Bottom-left: crested gecko holding a pale lavender-blue rune waystone. Bottom-right: sleepy cat resting on a small treasure chest. Clothing is dusty blue, ivory, lavender, bronze and leather; no green clothes or scene. Premium painterly game-character art, transparent background, no text or logos.

The header uses a page-specific pose, while empty states, filter source help and dictionary notes use small supporting stickers. CSS background-position selects each pose without introducing scripts or rendering text into images. Artwork stays decorative and cannot cover form controls. The common theme uses ivory, charcoal, slate-blue and light lavender; pastel surfaces retain slate text for readability.
