# Original workshop mascots

Asset: `docs/assets/workshop-companions.webp` (1600px-wide optimized banner).
Created 2026-11-05 with image generation for this project. This is original fan-tool art, not an official GGG asset. Earlier workbench imagery is not used by this theme.

Art brief: an adorable apricot crested-gecko adventurer in a moss-green cape and aged bronze armor, holding a blue rune waystone, accompanied by a charcoal cat artisan sorting currency orbs. Cozy candlelit gothic stone workshop, worn brass and wood, distant teal ruins. Painterly fantasy-game illustration, friendly proportions and expressive faces; characters on the right, quiet dark background on the left for readable HTML text. No text, logos or watermark. Palette: sage, cream, candle gold, copper and small blue gem accents.

The same original image supplies the common banner and decorative mascot avatars. Page text remains HTML. Background positioning changes responsively; text and controls are never baked into the art. Color and material rules are shared through `docs/workshop-theme.css`, included by the Python page builder for all four pages and therefore also by the desktop package.
