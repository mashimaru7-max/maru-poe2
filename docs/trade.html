지원 범위 · 검색 기준 · 자료 출처

한국어 빠른 옵션 34개와 영문을 포함한 옵션 목록을 제공해요. 거래 항목 자료는 기준 스냅샷이며 최신 전체 옵션이나 모든 부위 조합을 보장하지 않아요. 빠른 옵션은 해당 부위의 일반 옵션 범위와 맞지 않으면 검색을 막아요. 특수·고유 옵션은 정확한 거래 항목을 목록에서 선택하고 확인해 주세요.

‘에쉴100’은 장비의 최종 에너지 보호막 100 이상, ‘화저40’은 화염 저항 명시 옵션 40% 이상이에요. 여러 출처를 합산한 총저항·증가율·조건부 옵션은 각각 다른 검색 항목이에요. 모르는 단어나 충돌 조건은 자동으로 제외하지 않아요.

스탠다드·하드코어 외에는 거래소의 정확한 리그 이름을 직접 입력해 주세요. 선택한 리그와 부위는 브라우저에 보관해요. 입력창은 방문할 때 비어 있고, 저장한 검색은 직접 불러올 수 있어요. 검색 결과가 0개여도 입력이 틀렸다고 단정하지 않으며, 최종 검색 조건은 거래소에서 확인하세요.

단순 이상·이하·범위·원소 저항 합계와 가격 상한을 지원해요. 카오스 포함 저항 합계·초과·미만·‘또는’·예산 화폐 환산은 자동 처리하지 않아요. 원소 저항 합계는 화염·냉기·번개를 더한 값으로, 각 저항이 그 값 이상이라는 뜻은 아니에요. 합계 검색 항목 근거 (2026-09-22 확인 자료). 일반 별칭으로 원하는 옵션이 없으면 전체 목록에서 정확한 옵션을 선택하세요.
