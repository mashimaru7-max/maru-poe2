포함 조건은 모두 일치(AND) 또는 하나 이상(OR)으로 묶습니다. 제외 조건은 하나라도 발견되면 걸러냅니다. 상점과 창고에서 실제 적용은 각각 확인해 주세요.

옵션명은 poe.re의 POE2 한국어 자료를 참고했습니다. 짧은 표현은 이 카탈로그 안에서 중복을 검사합니다. 전체 게임 문구에 대한 무오류 보장은 아니며, 게임 내 검증은 아직 하지 않았습니다.

한글 자모 분해(NFD)를 기본으로 사용합니다. 고급 설정에서 일반 한글(NFC)과 길이 기준을 바꿀 수 있습니다. 웹 텍스트 검사는 JavaScript 기반 참고 검사입니다. 미감정 옵션과 옵션 합산값은 판별하지 않습니다.
