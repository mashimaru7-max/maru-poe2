# 아이템 이름·약칭 사전

확인일: 2026-11-05. 기존 재화 사전을 장비·고유 아이템·젬 등 전체 이름 검색으로 확장했습니다. 기존 URL `currency-aliases.html`은 유지합니다.

- 재화 이름 673종 → 전체 아이템 이름 **3,905종**. 고유 아이템 **766종** 포함.
- DB의 이름 있는 레코드 4,058개를 베이스와 영문 이름을 기준으로 3,895개로 정리했습니다. 같은 항목의 한글 표기 차이는 검색 보조에 보존했습니다.
- 기존 재화 사전의 DB 미수록 이름을 보완하고, 검색용 분류 묶음 10개도 유지합니다. 따라서 전체 검색 결과에는 이름 3,905개와 분류 묶음 10개, 총 3,915개 항목이 있습니다.
- `헤헌` / `헤드헌터` / `Headhunter`, 한영 이름, 재화 약칭, 띄어쓰기·대소문자·주얼/쥬얼, 이름+분류 복합 입력을 지원합니다.
- 분류·유형·확인된 약칭 여부를 함께 필터링합니다. 100개씩 페이지를 나누어 표시해도 검색은 전체 항목에 적용합니다.
- 한글 이름이 같은 고유 아이템은 베이스를 표시하고 서로 다른 레코드를 유지합니다. 일반적인 분류명인 ‘반지’ 등은 이름 하나로 한정하지 않고 관련 항목도 찾습니다.
- 기존 필터용 재화 별칭 데이터와 거래 검색 쿼리 로직은 변경하지 않습니다.

## 데이터와 갱신

원본: [Exiled Exchange 2의 POE2 한국어 아이템 DB](https://github.com/Kvan7/Exiled-Exchange-2/blob/cca30662bf31eaf38bd711e2ec1a6b899a06c40e/renderer/public/data/ko/items.ndjson).

DB의 저장소 최신 커밋은 확인 시점에 `cca30662bf31eaf38bd711e2ec1a6b899a06c40e`이며 날짜는 2026-09-06입니다. 현재 게임의 최신 전체 목록 또는 실제 거래 가능 여부를 보증하지 않습니다. 이름 없는 레코드 5개는 제외합니다. 분류가 불명확한 이름은 ‘분류·현재 사용 여부 미확인’으로 표시하며 임의로 거래 가능하다고 판정하지 않습니다.

분류와 기존 검색 보조는 `trade-catalog.js`의 고정 자료를 사용합니다. 한국 글에서 조사한 기존 재화 표기는 별도 ‘사용례 확인’으로 보존하며, `헤헌` 같은 추가 연결은 ‘검색 보조’로 구분합니다.

```sh
node scripts/build_item_dictionary.cjs /path/to/items.ndjson
node scripts/build_item_dictionary.cjs /path/to/items.ndjson --check
node --test tests/item-dictionary.test.cjs
python scripts/build_web.py
```

빌더는 검토한 원본 SHA-256 `66171815f015812419419d009f0aed5e37e73a54249b28b08f8dfcffa44c7233`를 확인합니다. 다른 원본으로 갱신할 때는 커밋·해시·지원 범위를 함께 검토하고 수정합니다. 압축된 이름 전용 데이터만 배포하므로 원본 아이템 아트·설명·옵션 문구는 포함하지 않습니다.

MIT 고지는 `THIRD_PARTY_NOTICES.md`, `licenses/trade-ko-MIT.txt`, `licenses/trade-data-MIT.txt`에 있으며, 전체 사전 JSON에도 완전한 라이선스 고지를 포함합니다.

## 검사

전체 DB 이름의 한글명·영문명·대체 한글 표기, 기존 재화 별칭, 헤드헌터 약칭, 분류·유형 교집합, 정확한 재화 등급 구분, 출처·라이선스가 보존되는지 자동 검사합니다. 이 확장 후 기존 검사를 포함한 Node 검사 36개가 통과했습니다.
